# Unity_Game_IT3
My attempt of making a unity game with the theme "Isolation"

Final idea (end goal)

Game story: Psychological horror where you play as a seal in the arctic, you have to find "The Giant Iceberg"

Gameplay: As a seal you have to traverse the difficult landscape of icebergs and swimming in the cold dark waters, where the player mobility changes based on the environment
The user has a setting where they can change the day/night weather

Horror aspect: Scripted events and audio usage - changing environment scene

Ending: Scripted event and transition to main menu
